5面试官最可能问的 5 个问题
每个问题配一句「5岁能懂」的答案，关键词已标绿。
Q1：它和普通聊天机器人有什么区别？
聊天机器人只动嘴给答案；它是 Agent，会调用工具改变电脑真实状态——真的去开浏览器、跑代码、改文件。
Q2：它怎么知道该用哪个工具？
每个工具都带一张说明书（tool schema：名字、能干啥、要什么参数）。大模型读完说明书，自己按需选择并填参数，这就是 Function Calling。
Q3：工具出错/失败了怎么办？
ReAct 循环天生会重试：报错也是「观察」结果。比如 Python 缺库，工具会自动 pip install 后重跑（ModuleNotFoundError 自动修复）。
Q4：MCP 是什么？为什么用它？
MCP 是「万能插座」标准协议：外部工具服务器插进来，Agent 自动发现并调用其工具（统一 mcp_ 前缀），不用为每个工具写接入代码。内置演示：文件系统服务器。
Q5：工具能改你电脑，安全吗？
这是产品设计取舍：定位是本地个人管家，非沙箱、可写可执行是刻意为之（CLAUDE.md 里明确写了不要加固成只读）。要诚实说清「放开」与「最小打扰、用户在场」的平衡。

④ 说透「坑与不足」—— 面试的加分区

真实踩过的坑：Windows 下 MCP 的 npx 必须写 npx.cmd 全路径；中文注释导致 pom 必须 UTF-8 编码否则编译报错；WebDriverManager 自动下驱动。
不足：记忆不持久、无 SSE 流式、没接 IM、没定时任务——正好是路线图，展示你的规划能力。
