为什么有些地方“看不到源码”？

1

agent.call(message) 是本项目能看到的入口，但 ReAct 的循环实现位于 spring-ai-alibaba-agent-framework 依赖里。所以页面用伪代码表示：发给模型 → 模型要工具 → 执行工具 → 把结果再发给模型 → 得到最终答案。

2

LLM 的地址和模型来自 application.yml：base-url、api-key、model。Spring Boot 自动创建 ChatModel，再通过构造函数注入到 ChatController。

3

Spring 的 @Service、@RestController、构造函数参数，是“自动接线”。你没有手动写 new SkillsAgent(...)，Spring 会替你创建并传入依赖。

调试时最容易误解的地方

① agent == null 只在第一次请求成立；后续请求复用同一个 Agent。② new MemorySaver() 只存内存，重启就忘。③ 前端活动栏是本地状态，不等于后端实时工具日志。④ Python 配置了 allowAllAccess(true)、允许 I/O 和创建进程，不能把它当成严格沙箱。
