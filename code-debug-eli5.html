调试时要记住的 3 件事

1. agent.call(message) 里面的 ReAct 循环来自依赖库，不在当前项目源码里；这里展示的是它的可理解流程。

2. `MemorySaver` 是内存记忆：后端重启后，对话上下文会消失。

3. Shell、文件、浏览器和 Python 都能影响真实电脑；代码注释里的“sandbox”不能自动等于严格安全隔离。
