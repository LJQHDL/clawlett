一次聊天会发生什么？

1

前端 React 聊天框把你的话发到后端 GET /chat?message=...。

2

ChatController 把话交给 SkillsAgent；第一次来时，它才创建 Agent。

3

Agent 把问题交给 LLM。LLM 像“指挥员”，判断要不要调用工具。

4

工具真的去做事：例如浏览器访问网页，Python 计算，文件工具读写文件。

5

工具结果回到 Agent；Agent 继续思考，最后把答案返回前端显示。

每个文件像什么？

ChatController.java
前台接待员：接收聊天请求。
SkillsAgent.java
总管：组装模型、工具、Skills、记忆。
PythonTool.java
计算员：在 GraalVM 里执行 Python。
BrowserTool.java
浏览员：用 Selenium 控制 Chrome。
application.yml
管家手册：端口、模型、API Key、MCP 地址。
frontend/src
控制台：聊天、加载状态、活动记录。

它的“积木”

🧠

Spring Boot：让 Java 后端启动并提供接口。

🔌

Spring AI：让程序可以和大模型、工具对话。

🔁

ReAct：不是只回答，而是“想一步、做一步”。

🧰

Skills：从 ~/.agents/skills 加载可复用技能。

🌉

MCP：像插座，让外部工具服务器接进来。

💾

MemorySaver：当前是内存记忆；程序重启后不会保留长期历史。

小朋友也要知道的注意事项

这个 Agent 能执行 Shell、读写文件、启动浏览器和安装 Python 包，所以它的权限很大。代码里的“sandboxed”是工具描述，不代表这里已经做了严格隔离；实际运行时要特别小心 API Key、文件目录和命令权限。

前端右侧的“活动记录”主要是本地 UI 状态：请求开始时显示，收到最终响应后更新，并不是后端实时推送的工具事件。
